# Arrivo Frontend

App Next.js principale per lo sviluppo dell'esperienza web Arrivo.

## Contenuto iniziale

- Next.js App Router
- React
- Tailwind CSS
- layout mobile-first statico
- cartelle `components`, `services`, `hooks`, `styles`, `lib`

## Script futuri

```bash
npm install
npm run dev
npm run build
npm run lint
```
